## التجربة الجديدة

صفحة `/local/` على موقع السحابة أصبحت صفحة تنزيل وشرح. ملف التنزيل `/api/downloads/windows` هو مثبّت EXE واحد، لا ZIP ولا CMD. يُثبّت للمستخدم الحالي بدون صلاحيات مسؤول، ويضيف اختصاراً لسطح المكتب وقائمة ابدأ وإدخالاً في قائمة التطبيقات المثبّتة لإزالته.

بعد التثبيت تظهر نافذة Brio وفيها تشغيل اللعبة، فتح لوحة المقدّم وإيقاف اللعبة. الخادم يعمل كعملية خلفية مخفية؛ لا تظهر نافذة أوامر. إيقاف اللعبة وإغلاق التطبيق يطلبان تأكيداً عند وجود خادم يعمل. تُرسل رسالة إيقاف إلى الخادم كي يغلق الاتصالات ويحفظ قاعدة البيانات قبل الخروج؛ التطبيق لا يجبر العملية على الإغلاق عند تعذّر الإيقاف الآمن.

المثبّت للمقدّم على Windows 10/11 x64 مع .NET Framework 4.8 المتوفر عادة ضمن ويندوز. محرك Node 24.11.1 مضمن. لا يحتاج المستخدم Node أو pnpm، ولا حساب Google لتشغيل LAN. التطبيق يستخدم واجهة عربية في هذا الإصدار، بينما واجهة اللعب تدعم العربية والإنكليزية.

ملفات التطبيق داخل `%LOCALAPPDATA%/Brio/versions/`، والبيانات داخل `%LOCALAPPDATA%/Brio/data/`. التحديث يضيف نسخة مستقلة ويحدّث الاختصارات، ولا يستبدل قاعدة البيانات. الإزالة تبقي البيانات. نسخ التطبيق السابقة لا تنظّف آلياً بعد التحديث في هذا الإصدار. حزم ZIP السابقة لا تنقل بياناتها تلقائياً؛ يمكن إعادة استيراد ملفات المسابقات، وتبقى النتائج القديمة في مسارها السابق.

## الأمن والتوزيع

المثبّت التجريبي غير موقّع رقمياً بعد. صفحة التنزيل توضّح هذا ولا تطلب تجاوز تحذيرات Windows. إذا منعته سياسة الجهاز أو SmartScreen، استخدم النسخة السحابية حتى توفير توقيع موثوق. شراء/إصدار شهادة توقيع أو ربط خدمة توقيع يحتاج حساب المالك وإعداداً منفصلاً؛ لم ننشئ شهادة ذاتية على جهاز المستخدم ولم نغيّر SmartScreen أو Firewall.

المثبّت لا يحتوي أسرار المزود أو قواعد المستخدم. يحتوي رخص Node والخط والمكتبات. فكّ الحزمة يرفض path traversal ويستخدم مجلداً جديداً. أداة الإزالة تقبل مجلد versions المحدد للتطبيق فقط وترفض linked folders، وتطلب إغلاق التطبيق قبل إزالة ملفاته.

Cloudflare Static Assets يحد الملف الواحد بـ25 MiB. تُرفع أجزاء ثابتة محدودة بـ16 MiB، وendpoint التنزيل يتحقق من manifest ويقدّمها كتدفق واحد مع Content-Disposition، دون تحميل المثبّت كله إلى ذاكرة Worker ودون إضافة R2 أو خطة مدفوعة. manifest يبيّن الحجم وSHA-256. لا يدعم استكمال تنزيل Range في هذا الإصدار؛ يعاد التنزيل إذا انقطع. راقب طلبات Worker عند توسيع الدعوات.

الملفات المنشورة مجمعة آلياً داخل apps/web/public/downloads/windows ومستبعدة من Git. لا تُضمّن ملفات التنزيل في حزمة LAN نفسها، لتجنب تضخم الحزمة بشكل متكرر. احتفظ بمخرجات release مع checksum عند النشر. البناء اللاحق بدون الحزمة لا يُعلن زر تنزيل يعمل؛ يجب اتباع الترتيب أدناه والتأكد من الملف قبل النشر.

## البناء

1. `pnpm install --frozen-lockfile`
2. `pnpm lan:build`
3. `pnpm lan:desktop` على Windows x64 مع Node 24.11.1 و.NET Framework compiler. رخصة الإصدار مضمنة في scripts/licenses.
4. `pnpm quality` يبني الويب السحابي ويضمّن ملفات التنزيل المجهزة.
5. `pnpm --filter @brio/worker exec wrangler deploy`
6. نزّل EXE من الموقع وتحقق من SHA-256 مقارنةً بـmanifest قبل الدعوات.

لا تُعد توزيع مجلد بيانات استخدمته. التطبيق يجمع ملفاته في releases بمجلد جديد، ويستبعد تنزيلات الموقع وبيانات .brio-lan. يبني Brio.exe وUninstall.exe ومثبّتاً يحوي payload مضغوطاً.

## الفحوص والحدود

- مقارنة manifest/الملفات واختبارات endpoint تشمل ملفاً واحداً بالبايتات المتوقعة، وفشل جزء مفقود أو مسار غير متوقع.
- اختبارات web والخادم وLAN مرّت؛ اختبارات LAN تشمل الإيقاف والاستعادة وقاعدة SQLite والـWebSocket. أُضيف اختبار مستقل يفك payload الحقيقي إلى مجلد تجريبي ويشغّل Node المضمن مرتين، ويتحقق من demo وإيقاف stdin الآمن وبقاء البيانات بعد إعادة التشغيل. لم يحتاج tsx أو pnpm في التطبيق المفكوك.
- عاينا نافذة التطبيق العربية وأزرارها عبر computer-use. بدأ منها الخادم ووصل health إلى `{status:ok,mode:lan}`. اختبرنا منع نسخة واجهة ثانية. لم نثبت التطبيق على حساب المستخدم ولم ننفّذ إزالة ملفات المستخدم كجزء من فحص الواجهة؛ اختبرنا فك payload نفسه دون إنشاء اختصارات أو سجل تثبيت.
- لا يوجد اختبار Windows نظيف، ولا توقيع رقمي، ولا بروفة iOS Safari/Android فعلية في هذه الجلسة. فحوص الموبايل السابقة محاكاة Chromium وتبقى موثقة بهذا الاسم. تشغيل اللعبة يتطلب شبكة تسمح للأجهزة بالتواصل وجهازاً مستيقظاً.
- تثبيت وإزالة الاختصارات والتسجيل في Apps بحاجة بروفة على جهاز Windows تجريبي قبل توصيف التجربة كإصدار مستقر. لا يوجد تحديث تلقائي أو بناء Mac/Linux في هذه النسخة.
